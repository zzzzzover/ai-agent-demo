# 示例资料说明

> **这里是演示用的虚构数据。**
> 项目「示例项目 X」、文中的人（甲 / 乙 / 丙）、日期、数字全部是编造的，
> **与任何真实组织、项目或个人无关**。它们不是从任何地方抓取或整理的，
> 是专门为这个 demo 写出来的。

每个文件开头都有同样的声明。这么啰嗦是故意的：这个目录用「里程碑 + 讨论记录」的
形态来模拟零散资料，乍看容易让人以为是谁的真实工作文档，所以把「这是假的」写在
最显眼的地方。

资料刻意做成「零散笔记」的样子——里程碑、讨论记录、决策记录分散在不同文件甚至子目录里，
这样才能体现 agent 需要先探查、再定位、最后综合，而不是读一个文件就能交差。

```bash
uv run agent-demo --root ./examples --task "把 notes 目录里的资料整理成一份项目进展报告，标注出处"
```

想换成自己的资料，直接改 `--root` 指向任意目录即可（agent 只能读写该目录内部）。
